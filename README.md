# 7samael7 Tap

## How do I install these formulae?

`brew install 7samael7/tap/<formula>`

Or `brew tap 7samael7/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "7samael7/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
